# Paper 001 — The Payout Gap

**Public Working Paper v1.0 · 2026-10-11 · Not peer-reviewed**

**Full text:** [working-paper-v1.0.md](working-paper-v1.0.md)

## Main proposition

A strategy can look attractive on a historical equity curve while failing to establish the existence, timing or reliability of external spendable cash. Return, high-water-mark recovery, modeled claims, modeled receipts, and verified actual bank receipts are **not interchangeable endpoints**.

The paper's central organizing device is the **six non-interchangeable clocks** table in §3.5. The cases in §5 are drawn from a single related private research program and use explicit evidence levels rather than a pooled sample.

## Read the results carefully

- **238 days** is a checkpoint-reported Toy A+C equity HWM recovery interval, **not a measured payout drought**.
- **140.17 days** is the median longest modeled *no-claim* gap in a separate Gate 1R one-year cohort export (169 eligible starts under one stated 14-day scenario). It is **not** a verified live payout wait.
- Reported CR2R/CR2F cash amounts are **simulated model receipts**, not bank records.
- UB execution approval was **insufficient evidence**, not demonstrated signal failure or certified deployability.
- No end-to-end fee-purchase-to-net-household-profit measurement is available.

## Evidence and release boundary

The underlying trading data, detailed internal version history, source code and internal links were intentionally excluded from public release. The internal numerical record had selected exports reconciled to their own event summaries but has **not** been independently regenerated. No universal pass/fail rate or real trading profit rate is inferred.

For source literature see the References section at the end of the paper; its scholarly references use stable DOI links. The public working paper is *methodological documentation*, not a reproducible benchmark package.
